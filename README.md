# Personal Portfolio & QA Showcase 🌸

A responsive personal portfolio website showcasing web development projects, interactive UI components, and software testing suites (including manual test design and Defect Life Cycle simulation).

🚀 **Live Demo:** [https://vikas-yuki.github.io/Myportfolio/](https://vikas-yuki.github.io/Myportfolio/)

---

## 📌 Featured Projects

* **SauceDemo E-Commerce Test Suite:** 25 functional, boundary, and edge-case manual test cases designed and executed for the SauceDemo platform using Excel and GitHub.
* **Jira Bug Tracking Simulator:** Interactive glassmorphic QA mini-game simulating the full Defect Life Cycle (New ➔ Assigned ➔ Fixed ➔ Verified ➔ Closed).
* **IMDb Media Discovery App:** Dynamic movie app evaluating DOM manipulation, real-time search/filtering logic, and responsive layouts.
* **To-Do Productivity App:** Task management app built to test dynamic state changes, local storage persistence, and boundary user inputs.
* **Online Grocery Platform:** Responsive e-commerce web interface built with modern Bootstrap components.

---

## 🛠 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap
* **QA & Testing:** Manual Testing, Test Case Design, Defect Tracking, Excel
* **Version Control & Hosting:** Git, GitHub, GitHub Pages
